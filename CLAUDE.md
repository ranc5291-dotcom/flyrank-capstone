# AI Development Rules

## Stack

- React
- JavaScript
- Node.js

## Conventions

- Write clean code
- Use meaningful names
- Reuse components
- Follow Conventional Commits

## Best Practices

- Keep components reusable
- Write comments only when necessary
- Use semantic HTML

## Additional Project Rules

- Use controlled React components for all forms.
- Validate all user inputs before submission.
- Use semantic HTML and accessibility attributes such as `aria-invalid` and `aria-describedby`.
- Extract reusable validation logic into separate utility files.
- Build and verify the project before committing AI-generated code.
